================================================================================
        改进多目标萤火虫算法（Enhanced Multi-Objective Firefly Algorithm，EMOFA）
                    ——面向含工时不确定再制造件的柔性车间鲁棒调度
================================================================================

【改进概述】
在原MOFA算法基础上，本文从以下六个维度进行改进：
  ① 引入反向学习初始化（Opposition-Based Learning, OBL），增强初始种群多样性；
  ② 引入外部精英档案（External Elite Archive），稳定维护当前已知最优非支配解；
  ③ 将固定步长参数α和光吸收参数γ改为自适应动态调整策略；
  ④ 改进二阶段飞行策略：以拥挤距离为导向选取目标个体，提升种群分布均匀性；
  ⑤ 引入自适应算子选择（Adaptive Operator Selection, AOS），动态调整邻域搜索
     算子（Swap/Insertion/Replacement）的使用概率；
  ⑥ 引入收敛性早停检测（基于超体积HV指标变化率），避免无效迭代浪费计算资源。

================================================================================
一、算法输入与参数
================================================================================

输入：
  - 工件集合：n个工件（其中s个再制造件，n-s个新品）
  - 机器集合：m台机器
  - 各工序可用机器集及加工时间矩阵
  - 再制造工件工序加工时间区间（均匀分布上下界）

参数设置（通过正交实验标定）：
  - 种群数量         N = 100
  - 最大迭代次数     I_max = 200
  - 外部档案容量     A_max = 100
  - 初始吸引度系数   β₀ = 1
  - 初始光吸收率     γ₀ = 0.06
  - 初始步长因子     α₀ = 1.2
  - 步长衰减系数     δ = 0.98          （每代自适应缩减步长）
  - 多样性阈值       σ_min = 0.05       （触发自适应步长放大的多样性下限）
  - HV停滞阈值       Δ_HV = 1×10⁻⁴    （连续K代HV变化量低于此值时早停）
  - HV停滞代数       K_stag = 30
  - 算子初始概率     P_swap = P_ins = P_rep = 1/3
  - 算子奖励系数     r_op = 0.1

================================================================================
二、算法整体流程
================================================================================

BEGIN EMOFA

  Step 1  【初始化】
    Step 1.1  基础种群初始化（同原MOFA的S4.3）
      - 工序序列（OS）：随机打乱工件编号排列，生成N/2个初始个体
      - 机器分配（MA）：以0.8概率选最短处理时间机器，以0.2概率随机选取
      - 生成初始种群 P₀（含N/2个个体）

    Step 1.2  反向学习初始化（OBL）
      - 对P₀中每个个体 xᵢ，生成其反向个体 xᵢ'：
          MA反向：对每道工序在可用机器集中取"对称"位置的机器
                  （若可用机器集大小为k，当前机器索引为j，则反向索引为k+1-j）
          OS反向：将工序序列整体翻转（reverse），保持可行性
      - 合并P₀与所有反向个体，构成候选集（共N个）
      - 计算全部候选个体的目标函数（Cmax, ε）
      - 对候选集执行快速非支配排序（FNS），保留前N个精英个体，构成初始种群P

    Step 1.3  初始化外部精英档案A
      - 对P执行FNS，将第一帕累托前沿F₁的所有个体加入档案A
      - 若|A| > A_max，按拥挤距离降序截断至A_max
      - 初始化档案更新轮次计数 t_A = 0

    Step 1.4  初始化自适应算子概率
      - P_swap = P_ins = P_rep = 1/3
      - 各算子成功次数计数器 cnt_swap = cnt_ins = cnt_rep = 0
      - 各算子调用次数计数器 use_swap = use_ins = use_rep = 0

    Step 1.5  初始化超体积记录
      - 计算初始档案A的超体积 HV_best = HV(A)
      - HV停滞计数器 stag_count = 0

  Step 2  【主迭代循环】  for t = 1 to I_max do

    Step 2.1  【自适应参数更新】
      - 计算当前种群多样性指标（均一化目标空间中个体间平均欧氏距离）：
            Div(t) = (1/N²) × Σᵢ Σⱼ dist(fᵢ, fⱼ)
      - 自适应步长更新：
          若 Div(t) < σ_min：α(t) = min(α(t-1) × 1.05，α₀ × 1.5)  （多样性不足时放大步长）
          否则：             α(t) = α(t-1) × δ                        （正常衰减）
      - 自适应光吸收率更新：
            γ(t) = γ₀ × exp(−t / I_max)                （迭代后期减弱距离衰减，增强全局搜索）

    Step 2.2  【快速非支配排序（FNS）确定亮度层级】
      - 对当前种群P中全部N个个体执行FNS
      - 输出分层结果：F₁（最亮，帕累托前沿）, F₂, F₃, …
      - 计算每个个体在其所在前沿内的拥挤距离 CD(i)

    Step 2.3  【被支配萤火虫的一阶段定向移动】
      - 对所有不在F₁中的被支配个体 i：
        a. 从档案A中随机选取一个目标个体 j（利用外部档案引导，而非仅从种群选取）
        b. 计算距离 r_ij（基于MA编码的欧氏距离，同原MOFA）
        c. 计算吸引力 β(r_ij) = β₀ × exp(−γ(t) × r_ij²)
        d. 机器编码更新（同原MOFA S4.5 步骤①②③）：
             - 差异编码 Δ = MA_j ⊕ MA_i（相同位置置0，不同位置保留MA_j值）
             - 筛选编码：生成随机数rand，若 α(t)×(rand−0.5) < β(r_ij)，保留该位，否则置0
             - 将筛选后的非零元素填入 MA_i 对应位置
        e. 工序编码更新（同原MOFA S4.5）：
             - 从目标个体j随机选L=2个工件，按j的相对顺序重排i中对应位置
        f. 解码并计算新个体 i' 的目标函数 (Cmax, ε)
        g. 若 i' 帕累托支配 i，则以 i' 替换 i；否则以β₀概率随机接受（模拟退火思想，
           β₀随迭代衰减：β₀(t) = β₀ × exp(−t / I_max)），增强跳出局部最优能力

    Step 2.4  【二阶段改进飞行：拥挤距离导向随机扰动】
      - 对每个萤火虫 i（包括非支配个体）：
        a. 拥挤距离导向目标选取：
             - 从档案A中选取拥挤距离最小的50%个体（拥挤区域）作为目标候选集
             - 若种群多样性 Div(t) < σ_min，从目标候选集中随机选取目标 j'
               （拥挤度低的区域优先被探索，提升分布均匀性）
             - 若 Div(t) ≥ σ_min，则随机从种群中选取任意个体 j'（同原MOFA）
        b. 按与Step 2.3相同的编码更新策略生成临时个体 i''
        c. 将 i'' 与 i 进行FNS比较，保留帕累托排名更优的个体

    Step 2.5  【非支配个体邻域搜索（含自适应算子选择AOS）】
      - 对F₁中每个非支配个体 xᵢ：
        a. 按自适应概率（P_swap, P_ins, P_rep）随机选择一种邻域算子
             轮盘赌选择：概率正比于各算子当前成功率估计值
        b. 执行所选算子，生成邻域解：
             Swap算子：在OS中随机选两位置，交换工件编号（同原MOFA）
             Insertion算子：在OS中随机选位置i和j，将i处工件编号插入j处（同原MOFA）
             Replacement算子：在MA中随机选一工序，从可用机器集重新分配不同机器（同原MOFA）
        c. 解码计算邻域解目标函数
        d. 更新算子调用计数器：use_op++
        e. 若邻域解帕累托支配原个体 xᵢ，则替换之，且 cnt_op++（成功计数+1）
      - 每隔10代更新一次算子概率（AOS更新）：
            成功率 R_op = cnt_op / max(use_op, 1)，op ∈ {swap, ins, rep}
            P_op = (R_op + ε_floor) / Σ(R_op' + ε_floor)   （ε_floor=0.05防止概率归零）
            重置 cnt_op = use_op = 0

    Step 2.6  【外部精英档案更新】
      - 将本次迭代后种群P中所有个体与档案A合并
      - 对合并集执行FNS，保留第一前沿F₁'中所有个体
      - 若 |F₁'| > A_max：
            按拥挤距离降序截断，优先保留分布稀疏区域的个体
      - 若 |F₁'| ≤ A_max：
            直接以F₁'更新档案A
      - 更新 t_A = t

    Step 2.7  【精英选择，维持种群规模为N】
      - 将当前种群P（经过Step 2.3~2.5更新后）与档案A合并为候选集
      - 按FNS前沿编号升序、同一前沿内拥挤距离降序，选取前N个个体更新种群P

    Step 2.8  【收敛性早停检测】
      - 计算当前档案A的超体积 HV_cur = HV(A)（以当前已知最差目标值作为参考点）
      - 若 |HV_cur − HV_best| / max(HV_best, 1) < Δ_HV：
            stag_count++
            若 stag_count ≥ K_stag：goto Step 3（提前终止）
      - 否则：
            HV_best = HV_cur
            stag_count = 0

  End for  （t = I_max 时自然终止）

  Step 3  【输出帕累托最优解集】
    - 输出外部精英档案A中的全部个体作为最终帕累托最优解集
    - 每个方案对应一组目标向量 (Cmax, ε)，覆盖从最短完工时间到最优鲁棒性的完整权衡曲线

END EMOFA

四、完整EMOFA算法伪代码
================================================================================

Algorithm EMOFA
Input:  工件集, 机器集, 加工时间矩阵, 不确定区间, 算法参数
Output: 帕累托最优解集 A

/* ------- 初始化阶段 ------- */
P ← 空集
FOR i = 1 TO N/2 DO
    xᵢ ← 启发式随机生成（OS随机排列，MA以0.8概率选最短处理时间机器）
    xᵢ' ← OBL反向个体（MA取对称机器索引，OS取翻转序列）
    P ← P ∪ {xᵢ, xᵢ'}
END FOR
对 P 中全部个体解码并计算目标函数 (Cmax, ε)
P ← FNS_Select(P, N)                // 取前N个精英个体
A ← 初始化外部档案（P中第一前沿个体，截断至A_max，按拥挤距离）
HV_best ← HV(A);  stag_count ← 0
α ← α₀;  γ ← γ₀
P_swap ← P_ins ← P_rep ← 1/3
cnt_swap ← cnt_ins ← cnt_rep ← 0
use_swap ← use_ins ← use_rep ← 0

/* ------- 主迭代 ------- */
FOR t = 1 TO I_max DO

    /* 自适应参数 */
    Div ← ComputeDiversity(P)
    IF Div < σ_min THEN α ← min(α × 1.05, α₀ × 1.5)
    ELSE α ← α × δ
    END IF
    γ ← γ₀ × exp(−t / I_max)

    /* FNS分层 */
    {F₁, F₂, …} ← FastNonDominatedSort(P)
    FOR EACH 个体 i IN P DO  CD(i) ← CrowdingDistance(i)  END FOR

    /* 一阶段：被支配萤火虫定向移动 */
    FOR EACH 个体 i NOT IN F₁ DO
        j ← RandomSelect(A)                         // 从外部档案随机选目标
        r_ij ← EuclideanDist(MA_i, MA_j)
        β ← β₀ × exp(−γ × r_ij²)
        MA_i' ← UpdateMA(MA_i, MA_j, α, β)
        OS_i' ← UpdateOS(OS_i, OS_j, L=2)
        i' ← Decode(MA_i', OS_i')
        IF i' dominates i THEN P[i] ← i'
        ELSE IF rand < β₀ × exp(−t / I_max) THEN P[i] ← i'  // 衰减接受
        END IF
    END FOR

    /* 二阶段：改进随机扰动飞行 */
    FOR EACH 个体 i IN P DO
        IF Div < σ_min THEN
            j' ← RandomSelect(A中拥挤距离最小的50%个体)
        ELSE
            j' ← RandomSelect(P)
        END IF
        i'' ← 按UpdateMA & UpdateOS生成临时个体
        IF FNS_Rank(i'') ≤ FNS_Rank(i) THEN P[i] ← i''
        END IF
    END FOR

    /* 邻域搜索（F₁中个体）+ AOS */
    FOR EACH 个体 i IN F₁ DO
        op ← RouletteSelect({swap, ins, rep}, {P_swap, P_ins, P_rep})
        xᵢ_new ← ApplyOperator(op, xᵢ)
        use_op++
        IF xᵢ_new dominates xᵢ THEN
            P[i] ← xᵢ_new
            cnt_op++
        END IF
    END FOR
    IF t mod 10 = 0 THEN UpdateAOS(P_swap, P_ins, P_rep, cnt, use)  END IF

    /* 档案更新 */
    A ← UpdateArchive(A ∪ P, A_max)              // FNS + 拥挤距离截断

    /* 精英选择维持种群规模 */
    P ← FNS_Select(P ∪ A, N)

    /* 早停检测 */
    HV_cur ← HV(A)
    IF |HV_cur − HV_best| / max(HV_best, 1) < Δ_HV THEN
        stag_count++
        IF stag_count ≥ K_stag THEN BREAK
        END IF
    ELSE
        HV_best ← HV_cur;  stag_count ← 0
    END IF

END FOR

RETURN A    // 外部精英档案即为最终帕累托最优解集

================================================================================
五、结果输出与鲁棒调度方案选取（同原方法）
================================================================================

1. 输出档案A中全部非支配方案，每个方案对应目标值对 (Cmax, ε)。
2. 按需从帕累托解集中选取方案：
   - 准时交货优先：选取 Cmax 最小的方案
   - 稳定运行优先：选取 ε 最小的方案
   - 综合权衡：决策者结合实际偏好权重选取折中方案（可采用TOPSIS等多属性决策方法辅助）
3. 对所选方案通过蒙特卡洛仿真（1000次）计算鲁棒性指标RM，验证方案稳定性：
   RM = (1/1000) × Σ (Cmax_实际 − Cmax_计划)
   RM值越小，表明调度方案越鲁棒。
